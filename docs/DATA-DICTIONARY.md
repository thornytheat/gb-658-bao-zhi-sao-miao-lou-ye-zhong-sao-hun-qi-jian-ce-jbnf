# 数据字典

- run_id：规则版本与输入 SHA-256 前 12 位组成的稳定批次标识。
- line_no：从 1 开始的物理来源行号，不因隔离或排序改变。
- business_key：本项目声明的业务唯一键，始终按字符串存储。
- reason_code：隔离原因的稳定英文编码。
- accepted：进入业务计算的记录数。
- quarantined：保留证据但不参与业务计算的记录数。
- 数值：金额、税额、用量和权重使用 Decimal；对外序列化为字符串。
- 时间：存储为带偏移的 ISO 8601，分桶使用半开区间。
- 空值：缺失键、空串和业务哨兵分别记录。
- 幂等：完整输入字节与规则版本相同则复用 run_id，不新增结果。
- attribution：扫描件归属。CONFIRMED（页眉一致）、REASSIGNED（补证确认）、PENDING（页眉指向他期待裁决）、UNKNOWN（页眉空或不可辨）。
- action：缺页清单动作。RESCAN（确定无候选，直接补扫）、WAIT（有候选但归属未定，先等裁决）。
- status：清单页状态。MISSING（缺页待扫）、HOLD（待裁决候选占位）。
- listing version_id：规则版本加清单输入（原始行、应有页数、改期覆盖）的稳定摘要；同一输入复用旧版。
- 改期事件：追加写入，一件扫描的当前归属取最新事件；request_key 相同的重复提交不再记新事件。
